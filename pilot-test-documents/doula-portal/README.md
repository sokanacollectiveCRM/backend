# Doula portal upload files

These files are for the test dashboard only. Each one is marked as a pilot test file, not a real credential.

Upload them on the doula Documents tab. A doula stays inactive until an admin approves all five required files.

| File | Choose this type in the form |
| --- | --- |
| 01-background-check.pdf | Background Check |
| 02-liability-insurance-certificate.pdf | Liability Insurance Certificate |
| 03-training-certificate.pdf | Training Certificate |
| 04-w9.pdf | W9 |
| 05-direct-deposit-form.pdf | Direct Deposit Form |
| 06-license-optional.pdf | License (optional) |

Accepted formats are PDF, PNG, and JPEG. Each file must be under 10 MB.
